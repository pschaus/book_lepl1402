Programming Concepts with Java#

LEPL1402 — Université catholique de Louvain (UCLouvain)

Authors: Sébastien Jodogne, Ramin Sadre, Pierre Schaus

Complete Course Textbook (PDF)

Download the entire 200+ page textbook covering all 6 course parts, optimized for offline reading and printing.

Download PDF Book
Part 1
From Python to Java

Syntax differences, primitive types, array and string memory representations, methods, and control flow.

 Part 2
Object-Oriented Programming

Classes, encapsulation, inheritance, polymorphism, abstract classes, interfaces, and GUI observers.

 Part 3
Software Testing

Unit testing principles, black-box vs white-box, control flow coverage, edge cases, and JUnit framework.

 Part 4
Complexity & Data Structures

Asymptotic notation (Big-O), linked lists, stacks, trees, binary search trees, hash maps, and iterators.

 Part 5
Parallel Computing

Multithreading, thread pools, race conditions, mutual exclusion, monitors, and concurrent algorithms.

 Part 6
Functional Programming

Nested and anonymous classes, lambda expressions, Java Streams API, lazy evaluation, and immutable data structures.
